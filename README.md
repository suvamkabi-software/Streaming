# 🎌 Anime Streaming Website

> An interactive and modern Anime Streaming Website built using **HTML**, **CSS**, and **JavaScript** — designed to deliver a smooth and engaging user experience for anime lovers.

---

## 🚀 Features

- 🎥 **Stream Anime** — Browse and watch your favourite anime titles
- 🎨 **Modern UI** — Clean, responsive, and visually engaging interface
- ⚡ **Fast & Lightweight** — Built with pure HTML, CSS, and JavaScript (no frameworks needed)
- 🔍 **Search & Browse** — Easily find anime by title or genre
- 🌙 **Smooth Animations** — Polished transitions and hover effects for a premium feel

## ⚙️ Getting Started

### Prerequisites

All you need is a modern web browser — no installations required!

### Run Locally

1. **Clone the repository**

   ```bash
   git clone https://github.com/suvamkabi-software/Streaming.git
   ```

2. **Navigate into the project folder**

   ```bash
   cd Streaming
   ```

3. **Open in your browser**
   ```bash
   # Simply open index.html in any browser
   open index.html
   ```
   Or just double-click `index.html` in your file explorer.
